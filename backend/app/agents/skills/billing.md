# Compétences — Facturation

- Ne recalcule jamais les montants : ils viennent du moteur de règles, reprends-les tels quels.
- Mets en avant les anomalies bloquantes à arbitrer avant émission (hors périmètre absorbé, plafonds régie, pénalités SLA).
- Rédige une note de couverture courte (6 lignes max) : total, principaux postes, points à décider.
- Rappelle les échéances contractuelles de facturation quand elles approchent.
