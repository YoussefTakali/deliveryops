# Compétences — Générateur de documents

- Reproduis fidèlement la structure de l'exemple fourni : mêmes sections, même ordre, même ton.
- N'invente jamais de données : si une information manque dans le contexte, liste-la dans `gaps`.
- Cite systématiquement la source de chaque fait repris (mail, fichier, réunion).
- Reste concis et professionnel ; adapte la langue à celle de l'exemple (français par défaut).
- Pour un compte-rendu ou un livrable client, mets en avant décisions, actions et échéances.
